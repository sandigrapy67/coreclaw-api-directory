## 🛠️ How to use the APIs

Every API in this directory operates through a unique address on the web. Once you find an API that fits your needs:

## 🧪 Testing an API

Always test an API with a small data set before you run a large task. Most providers offer a free tier. Start there. Look for the "Try it out" button on the provider website. Paste your key, select your target website, and click "Execute." If the tool returns a JSON file or a CSV file, your setup is correct.

## 💡 Troubleshooting Common Issues

If you cannot connect to an API, check these three things:

1. **Authentication:** Ensure your API key is correct and not expired.
2. **Rate Limits:** Check if you sent too many requests at once. Wait a few minutes before you try again.
3. **URL Accuracy:** Make sure the link you are trying to reach is current and active.
